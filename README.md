
# FieldKit

FieldKit is my personal, modular Linux cybersecurity toolkit.

## Goals

- Rebuild my Lubuntu workstation efficiently.
- Install selected tools through an interactive menu.
- Keep installation scripts organized and maintainable.
- Document my cybersecurity learning journey.

## Current features

- Interactive tool selection
- Batch installation
- APT-based package management
- Ubuntu-based system check

## Requirements

- Ubuntu or Lubuntu
- Internet connection
- Git and Bash
- A user account with sudo privileges

## Usage

```bash
chmod +x fieldkit.sh
./fieldkit.sh
```
